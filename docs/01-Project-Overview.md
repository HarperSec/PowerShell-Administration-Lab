# Project Overview

## Purpose

The purpose of this lab is to develop practical PowerShell administration skills with a focus on Identity and Access Management (IAM). PowerShell is commonly used in Windows enterprise environments to automate administrative tasks, manage Active Directory objects, and perform identity-related operations at scale.

This project demonstrates how PowerShell can be used to manage user accounts, security groups, account access, and identity lifecycle tasks more efficiently than performing each action manually through graphical administration tools.

## Lab Goals

The goals of this project are to:

* Learn PowerShell commands and administrative workflows
* Use PowerShell to manage Active Directory users
* Use PowerShell to manage Active Directory groups
* Automate common identity administration tasks
* Practice user provisioning and deprovisioning
* Generate Active Directory reports
* Document PowerShell commands and troubleshooting steps

## IAM Relevance

Identity and Access Management involves managing digital identities and controlling access to systems, applications, and resources.

PowerShell supports IAM administration by allowing administrators to automate tasks such as:

* Creating user accounts
* Disabling user accounts
* Resetting passwords
* Managing group memberships
* Reviewing user and group information
* Identifying inactive or disabled accounts
* Generating identity and access reports

Automation helps reduce repetitive manual work, improve consistency, and support administrative tasks across larger environments.

# PowerShell Administration Lab

## Project Overview

This project demonstrates the use of PowerShell to perform Windows Server and Active Directory administrative tasks. The lab focuses on automating common Identity and Access Management (IAM) responsibilities, including user account management, group membership, account lifecycle tasks, and administrative reporting.

The goal of this project is to develop practical PowerShell skills that can be applied to enterprise identity administration and security operations.

## Technologies Used

* Windows Server 2025
* Active Directory Domain Services (AD DS)
* PowerShell
* Active Directory PowerShell Module
* Windows 11
* GitHub

## Lab Environment

* **Domain:** `harper.local`
* **Domain Controller:** Windows Server 2025
* **Client Device:** Windows 11
* **Administration Tool:** PowerShell

## Skills Demonstrated

* PowerShell cmdlet navigation
* PowerShell pipelines and filtering
* Active Directory user management
* Active Directory group management
* User account provisioning
* User account deprovisioning
* Group membership management
* Identity administration automation
* Active Directory reporting
* PowerShell troubleshooting
